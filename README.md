# Bookstore_Database
This project involves the use of SQL in order to create a simple yet interesting Bookstore Database. I used Oracle APEX(Application Express) to create my database.

This repository includes 5 important files. 

- Bookstore_Project_Document: A word document that provides a thorough description with pictures of the project.
- RS_Schema: An image that shows relational schema of the database.
- ERD_diagram: An image that shows entity relationshp diagram of the database.
- SQLQuery: A .txt file that gives all queries(CREATE,DROP, INSERT, DELETE, UPDATE, etc.) used for the project.
- SuccessfulExecutionOnAPEX: An image that shows the execution of the queries from SQLQuery text file.
